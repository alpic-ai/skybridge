The same [view](/build/view) runs inside every host: Claude, Cursor, Goose, and others. `useHost` reports which one, taken from the MCP Apps `ui/initialize` handshake, so the view can adapt copy, shortcuts, or layout to the host it's rendering in. It runs only on MCP Apps hosts; the name is normalized to a [`Host`](#host) slug when recognized, otherwise passed through as a raw string.

## Example

An empty state suggests the next action using the wording that fits the host.

```tsx highlight={4}
import { useHost } from "skybridge/web";

function EmptyState() {
  const { name } = useHost();
  const hint =
    name === "claude"
      ? "Ask Claude to add your first item."
      : "Send a message to add your first item.";

  return <p className="empty">{hint}</p>;
}
```

## Returns

### `name`

```tsx
name: Host | (string & {}) | undefined;
```

The host's reported name. It resolves to a [`Host`](#host) slug for recognized hosts, a raw string for hosts not yet mapped, and `undefined` until the handshake completes — the view renders first and re-renders once the host responds. The `(string & {})` keeps the known slugs in autocomplete while still accepting any string.

### `version`

```tsx
version: string | undefined;
```

The host's version string, or `undefined` until the handshake completes.

### `capabilities`

```tsx
capabilities: McpUiHostCapabilities | undefined;
```

The host's MCP Apps capabilities from the handshake, such as `downloadFile`, `openLinks`, `message` or `experimental`. `undefined` until the handshake completes.

### `openai`

```tsx
openai: {
  resource: boolean;
  modelContext: boolean;
  message: boolean;
  files: boolean;
};
```

<Info>
This is an [OpenAI MCP extension](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md), not part of MCP or MCP Apps. Only **ChatGPT** supports it, and other hosts ignore it.
</Info>

Which [OpenAI MCP extensions](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md) the host supports. A flag is `true` only when the host advertises `experimental["openai/<name>"]`, so every flag is `false` before the handshake and on hosts other than **ChatGPT**.

| Flag | Extension |
| --- | --- |
| `resource` | Read, subscribe to and write the file opened through a file entrypoint. |
| `modelContext` | Titles, thumbnails and background content in model context. |
| `message` | Messages sent to a new conversation, and titled items in a message. |
| `files` | Open a local file in ChatGPT. |

```tsx
const { openai } = useHost();

return openai.files ? <OpenInChatGPTButton /> : null;
```

## Host

The recognized hosts, as normalized slugs. An unrecognized host surfaces its raw reported name instead.

```tsx
type Host =
  | "chatgpt"
  | "claude"
  | "cursor"
  | "goose"
  | "mistral-vibe"
  | "alpic";
```

| Slug | Reported `hostInfo.name` |
| --- | --- |
| `chatgpt` | `chatgpt` |
| `claude` | `Claude` |
| `cursor` | `Cursor` |
| `goose` | `MCP-UI Host` |
| `mistral-vibe` | `Le Chat` |
| `alpic` | `alpic-playground` |
