Your [view](/build/view) renders inside the host's surface, on its terms: a bounded height to fit and edges to keep clear of device chrome. `useViewport` reports those constraints so the view can size itself to the space the host actually gives it. It re-renders on every resize, so read the host theme from [`useUser`](/api-reference/use-user) instead.

## Example

The carousel fits its scroll area to the height the host offers and keeps content clear of notches and home indicators.

```tsx highlight={4,9,11-14}
import { useViewport } from "skybridge/web";

function Carousel({ products }: { products: Product[] }) {
  const { maxHeight, safeArea } = useViewport();

  return (
    <div
      style={{
        maxHeight,
        overflowY: "auto",
        paddingTop: safeArea.insets.top,
        paddingRight: safeArea.insets.right,
        paddingBottom: safeArea.insets.bottom,
        paddingLeft: safeArea.insets.left,
      }}
    >
      {products.map((product) => (
        <ProductCard key={product.id} product={product} />
      ))}
    </div>
  );
}
```

## Returns

`useViewport` returns the host's current viewport for the view, as a `ViewportState`.

### `maxHeight`

```tsx
maxHeight: number | undefined;
```

The maximum height in pixels the host gives the view. It is `undefined` when the host does not report a height limit. It updates as the host resizes the view's container.

### `safeArea`

```tsx
safeArea: SafeArea;
```

The pixel insets the view should keep clear of host chrome and device cutouts (notches, rounded corners, home indicators). When the host reports no insets, every side is `0`.

```tsx
type SafeArea = {
  insets: SafeAreaInsets;
};

type SafeAreaInsets = {
  top: number;
  right: number;
  bottom: number;
  left: number;
};
```
