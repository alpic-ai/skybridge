`useModelContext` sends content blocks to the model through `ui/update-model-context`. **ChatGPT** shows each block as a composer attachment the user can remove, and reports the attached context back so the view stays in sync. Each update replaces the context the view attached before.

## Example

A product view attaches the selected variant with a title and a thumbnail.

```tsx highlight={4,9-19}
import { useModelContext, useViewState } from "skybridge/web";

function VariantPicker({ variants }: { variants: Variant[] }) {
  const { supported, update } = useModelContext();
  const [selection, setSelection] = useViewState(
    { id: variants[0].id },
    { modelContext: false },
  );

  const select = (variant: Variant) => {
    setSelection({ id: variant.id });
    if (supported) {
      update({
        content: [
          {
            type: "text",
            text: `Selected ${variant.name}, ${variant.price}`,
            _meta: {
              "openai/title": variant.name,
              "openai/thumbnail": { src: variant.imageUrl },
            },
          },
        ],
      });
    }
  };

  return <VariantList variants={variants} selected={selection.id} onSelect={select} />;
}
```

## Returns

### `supported`

```tsx
supported: boolean;
```

Whether the host advertises the `openai/modelContext` extension. `false` before the handshake and on hosts other than **ChatGPT**.

### `context`

```tsx
context: {
  updateId: string;
  content?: ContentBlock[];
  structuredContent?: Record<string, unknown>;
} | null | undefined;
```

The context this view attached, as the host reports it. It becomes `null` once the user removes it from the composer, and stays `undefined` when the host never reported one.

### `update`

```tsx
update: (params: {
  content?: ContentBlock[];
  structuredContent?: Record<string, unknown>;
}) => Promise<void>;
```

Replaces the view's model context. Rejects with a `NotSupportedError` on hosts that don't advertise the extension. Content blocks accept this presentation metadata:

| Field | Effect |
| --- | --- |
| `_meta["openai/title"]` | Label of a text attachment, alt text of an image. |
| `_meta["openai/thumbnail"]` | Thumbnail of a text attachment, as an MCP `Icon`. A square image of at least 128x128 pixels works best. |
| `annotations.audience: ["assistant"]` | Sends the block to the model without showing an attachment. |

<Warning>
A [`useViewState`](/api-reference/use-view-state) that shares its state with the model writes the same context and replaces these attachments. Pass `{ modelContext: false }` to it when the view uses `useModelContext`.
</Warning>
